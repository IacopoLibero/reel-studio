# Brand template

Do not edit this folder for a real brand. Create a brand from it:

    ./scripts/new-brand.sh my-brand

That copies this folder to `brand/my-brand/`, fills in `{{BRAND}}` and asks for the name, website and colours.
Put the brand logo in `brand/my-brand/logo.png`
(the template has a transparent 1x1 placeholder) and record the voice sample as described in `voice-sample.md`.
